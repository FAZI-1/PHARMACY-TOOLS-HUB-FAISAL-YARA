Static, deployment-ready version of the Pharmacy Tools Hub with two additional live tools:

- Taper Check — https://taper-iiq-yara-ten.vercel.app
- CompoundCare — https://compounding-tool-beige.vercel.app

## Deploy

### GitHub + Vercel
1. Create a new GitHub repository or replace the files in the existing hub repository.
2. Upload `index.html`, `styles.css`, `script.js`, and `vercel.json` to the repository root.
3. In Vercel, import the repository.
4. Framework Preset: **Other**.
5. Build Command: leave empty.
6. Output Directory: leave empty / default.
7. Deploy.

No environment variables, database, package install, or build step is required.
